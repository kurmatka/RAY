# RAY — голосовой ассистент для Windows

**RAY** — голосовой ассистент для Windows, написанный на Python.

Он умеет распознавать русскую речь, реагировать на ключевое слово **«Рей»**, выполнять системные команды, запускать приложения и сайты, управлять некоторыми функциями Windows и отвечать голосом.

> Проект находится в активной разработке.

---

## Возможности

* Распознавание русской речи
* Активация по ключевому слову **«Рей»**
* Голосовое выполнение команд
* Озвучивание ответов
* Запуск приложений
* Открытие сайтов
* Работа с системными функциями Windows
* Управление громкостью
* Открытие папок
* Калькулятор, Блокнот и другие системные приложения
* Диалоговый режим после активации
* Fuzzy-поиск команд для обработки небольших ошибок распознавания
* Графический интерфейс на Tkinter
* История выполненных команд
* Логи работы
* Поддержка опасных команд с подтверждением

---

## Примеры команд

После запуска скажи:

```text
Рей, открой браузер
```

или:

```text
Рей, открой YouTube
```

Другие примеры:

```text
Рей, открой Discord
Рей, открой Telegram
Рей, открой Steam
Рей, открой проводник
Рей, открой калькулятор
Рей, который час
Рей, какая сегодня дата
Рей, увеличь громкость
Рей, выключи компьютер
```

Также можно сначала сказать:

```text
Рей
```

После этого RAY перейдёт в режим ожидания команды.

## Технологии

Проект написан на **Python**.

Основные технологии:

* Python
* Tkinter
* Vosk
* SoundDevice
* pyttsx3
* Git
* Windows API

Для распознавания речи используется модель **Vosk**.

Для синтеза речи используется **pyttsx3** с голосом Windows.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/kurmatka/RAY.git
cd RAY
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
```

### 3. Активация окружения

```powershell
.venv\Scripts\activate
```

### 4. Установка зависимостей

Если в проекте используется `requirements.txt`:

```powershell
pip install -r requirements.txt
```
